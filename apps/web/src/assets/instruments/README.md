# Instrument images

Generated for Phase 9b with OpenAI image generation, at Jayesh's request. No external image service is used at runtime.

- `guitar-parts.webp`: photographic acoustic guitar anatomy with English labels and a separate electric pickup close-up, used in the beginner lesson.
- `piano.webp`: grand piano cutout, used in instrument selection and settings.
- `guitar.webp`: acoustic guitar cutout, used in instrument selection and settings.

The web assets are WebP exports of the generated PNGs, preserving transparency for the instrument cutouts. Keep labels readable, provide text alternatives, and check dark and light themes when replacing them.
